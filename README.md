# Геномный тренажёр

Учебный сайт по геномике и статистике для омики на русском: 11 модулей, симуляторы, примеры кода с настоящим выводом, самопроверка и вопросы для собеседования. Все примеры построены вокруг пилотного сравнения двух гаплотипов (hap1 и hap2) у трёх видов летучих мышей.

Страница: https://varvarayukhina.github.io/genomics-trainer/

## Что внутри

- `index.html` — готовая страница (одним файлом, работает без сервера; из интернета нужен только шрифт).
- `src/` — HTML модулей, `js/` — интерактив, `snippets/` — примеры кода и их вывод (`snippets/out/`).
- `data/pilot/` — таблицы пилота (`family_summary.tsv`, `assembly_report.tsv`), по которым строятся график и таблицы.
- `build.py` — сборка: `uv run --with pygments python build.py`.

## Важно

- Числа пилота — автоматические подсчёты miniprot без ручной проверки, по трём особям. Это не оценка числа копий у вида.
- Примеры на Python и R запущены, их вывод лежит в `snippets/out/`. Шаблоны Scanpy, GATK и команды пилота не запускались в этом репозитории, и на странице они так подписаны.
- Симуляторы учебные, они не показывают реальные данные.
- Содержание не проверялось экспертом: сверяй цифры и названия с первоисточниками.
