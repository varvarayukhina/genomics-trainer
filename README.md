# Тренажёр биоинформатики

Учебный сайт на русском: от биологического вопроса к данным, коду и статистике. Страница: https://varvarayukhina.github.io/genomics-trainer/

## Что внутри

- **Карта задач.** Биологический вопрос, нужные данные, метод, инструменты, результат, как проверить и главная ловушка.
- **Модули** по геному и гаплотипам, сборке, форматам файлов, выравниванию, семействам генов, статистике для омики, одноклеточным данным, пайплайнам. Симуляторы, примеры кода с настоящим выводом, самопроверка.
- **Практикум с кодом.** 18 задач на Python. Код запускается в браузере (Pyodide), тесты проверяют решение, часть тестов скрыта. Эталонные решения проверены в настоящем Pyodide.
- **Читать чужой код.** Репозитории из научных статей и вопросы по ним (подборка собирается).
- **Собеседование и словарь.**
- Все примеры построены вокруг пилота: сравнение двух гаплотипов (hap1 и hap2) у трёх видов летучих мышей.

## Структура

- `index.html` — готовая страница, одним файлом.
- `src/` — HTML модулей и `harness.py` (проверка решений), `js/` — интерактив, `snippets/` — примеры кода и их вывод.
- `data/pilot/` — таблицы пилота, по ним строятся графики.
- `make_tasks.py` — генерирует `js/tasks.js`: считает ожидаемые ответы эталонными решениями и проверяет, что заготовки не проходят тесты.
- `build.py` — сборка: `uv run --with pygments python build.py`.

## Важно

- Числа пилота — автоматические подсчёты miniprot без ручной проверки, по трём особям. Это не оценка числа копий у вида.
- Примеры Python и R запущены, вывод лежит в `snippets/out/`. Шаблоны Scanpy, GATK и команды пилота не запускались в этом репозитории, на странице они так подписаны.
- Симуляторы учебные, не данные.
- Содержание не проверено экспертом: сверяй цифры и названия с первоисточниками.
- Практикуму нужен интернет: Python скачивается с jsDelivr при первом запуске.
