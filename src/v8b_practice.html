Практикум с кодом

Здесь ты пишешь настоящий код на Python, нажимаешь «Проверить» и получаешь результат тестов. Каждая задача — маленький кусок реального анализа: GC-состав, N50, CIGAR, фильтр VCF, поиск преждевременного стопа, перестановочный тест, поправка BH.

Как это работает Python (версия 3.12) запускается прямо в браузере через Pyodide. При первом запуске он скачает около 12 МБ, дальше работает из кэша. Нужен интернет и открытие страницы по адресу на GitHub Pages: в закрытом просмотрщике артефакта код не запустится. Код решения сохраняется в этом браузере.

Как решать

  • Сначала прочитай пример и вручную пойми, что должно получиться. Потом пиши код.
  • Если тест не прошёл, смотри «Ожидалось» и «Получено»: расхождение подсказывает, где ошибка.
  • print() работает: вывод покажется ниже.
  • Скрытые тесты проверяют крайние случаи (пустая строка, один элемент, регистр). Они нужны, чтобы нельзя было подогнать под примеры.
  • Подсказки открываются по одной. Решение появляется после первой проверки: сначала попробуй сама.
